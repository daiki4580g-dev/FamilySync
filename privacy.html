プライバシーポリシー

最終更新日：2026年8月6日

FamilySync（以下「本アプリ」）は、利用者のプライバシーを尊重し、 本アプリで取り扱う情報について、以下のとおり定めます。

1．取得または取り扱う情報

本アプリは、提供する機能に応じて、次の情報を取得または取り扱う場合があります。

  • Googleアカウントに関する情報（表示名、メールアドレス、ユーザー識別情報など）
  • Googleカレンダーの一覧および予定情報
  • FamilySync内で作成した共有予定、目的別カレンダー、家族グループおよびメンバー情報
  • 通知設定、端末のプッシュ通知用トークン
  • アプリの動作確認、障害解析および品質改善に必要な端末・利用状況・診断情報
  • 広告配信に必要な端末情報、広告識別子その他広告サービスが取り扱う情報（広告機能を利用する場合）

2．情報の利用目的

  • ユーザー認証およびアカウント管理
  • Googleカレンダーとの連携、表示、作成、更新および削除
  • 家族メンバー間での予定共有
  • 予定の追加、変更および削除に関する通知
  • 利用者からのお問い合わせへの対応
  • 不具合の調査、セキュリティ確保およびサービス改善
  • 広告の表示、効果測定および不正利用防止（広告機能を利用する場合）

3．Googleユーザーデータの利用

本アプリは、利用者の同意に基づきGoogleカレンダーへアクセスします。 取得したGoogleユーザーデータは、カレンダーの表示・同期および利用者が指定した予定操作のためにのみ利用します。 本アプリがGoogleユーザーデータを販売することはありません。

Googleアカウントとの連携は、アプリ内のログアウト操作またはGoogleアカウントの設定から解除できます。

4．外部サービス

本アプリでは、機能提供のために次の外部サービスを利用する場合があります。

  • Google Sign-In
  • Google Calendar API
  • Firebase Authentication
  • Cloud Firestore
  • Firebase Cloud Messaging
  • Firebase App Checkその他Firebase関連サービス
  • Google Mobile Adsその他広告関連サービス（広告機能を利用する場合）

各サービスにおける情報の取り扱いは、それぞれの提供事業者のプライバシーポリシー等に従います。

5．情報の保存

  • 家族共有予定、家族グループ、目的別カレンダー等は、Google Cloud／Firebase上に保存される場合があります。
  • 個人予定の一部は端末内に保存されます。
  • Googleカレンダーの予定は、Googleのサービス上に保存されます。

情報は、サービス提供、法令遵守、セキュリティ確保および紛争対応に必要な期間に限り保持します。

6．第三者への提供

本アプリは、法令に基づく場合、利用者の同意がある場合、または本ポリシーに記載した外部サービスを 機能提供に必要な範囲で利用する場合を除き、個人情報を第三者へ販売・提供しません。

7．安全管理

本アプリは、通信の暗号化、認証、アクセス制御その他合理的な安全管理措置を講じます。 ただし、インターネット上の通信や保存について完全な安全性を保証するものではありません。

8．利用者による管理・削除

利用者は、アプリ内の機能またはお問い合わせ窓口を通じて、登録情報の確認、修正、 連携解除および削除について申し出ることができます。

アカウント削除の方法がアプリ内に用意されている場合は、当該機能をご利用ください。 利用できない場合は、下記お問い合わせ先へご連絡ください。

9．子どもの利用

未成年者が本アプリを利用する場合は、必要に応じて保護者の同意および管理のもとで利用してください。

10．本ポリシーの変更

本ポリシーは、機能変更、法令改正その他必要に応じて改定することがあります。 重要な変更がある場合は、本ページまたはアプリ内でお知らせします。
