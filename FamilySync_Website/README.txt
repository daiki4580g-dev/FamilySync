# FamilySync Website

GitHub Pages用の公式サイト一式です。

## 含まれるファイル

- `index.html`：トップページ
- `privacy.html`：プライバシーポリシー
- `terms.html`：利用規約
- `style.css`：共通デザイン

## GitHubへのアップロード

4ファイルをリポジトリのルートへアップロードしてください。
GitHub Pagesが `main` / `(root)` に設定されていれば、自動的に公開されます。

公開予定URL：

- https://daiki4580g-dev.github.io/FamilySync/
- https://daiki4580g-dev.github.io/FamilySync/privacy.html
- https://daiki4580g-dev.github.io/FamilySync/terms.html

## 注意

プライバシーポリシーと利用規約は、実際のアプリ機能・広告設定・データ削除方法・App Store Connectの申告内容に合わせて、公開前に最終確認してください。
